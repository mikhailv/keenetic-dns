### Columns in IP2PROXY-LITE-PX12.CIDR.CSV

- **CIDR Range**: The network range in CIDR notation (e.g., 1.0.0.0/24).
- **Proxy Type**: The type of proxy (e.g., VPN, Open Proxy, Data Center).
- **Country Code**: ISO 3166-1 two-character country code.
- **Country Name**: ISO 3166-1 country name.
- **Region Name**: Region or state name.
- **City Name**: City name.
- **ISP**: Internet Service Provider or company's name.
- **Domain**: Domain name associated with the IP address.
- **Usage Type**: Usage type code (e.g., DCH, ISP, SES).
- **ASN**: Autonomous System Number.
- **Last Seen**: The last date the proxy was active.
- **Threat**: Known threat types (e.g., botnet, scanner).
- **Residential**: Indicator of whether it is a residential proxy (RES or empty).
- **Provider**: Name of the VPN provider.
- **Fraud Score**: The calculated fraud score for the proxy.
